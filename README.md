# Data Analytics Projects

This repository showcases hands-on data analytics projects created using Excel and Power BI.
The projects focus on data cleaning, analysis, visualization, and dashboard development.

## Projects

### Excel – Sales Data Analysis (Vrinda Store & Blinkit)
*Tools:* Advanced Excel, Power Pivot, KPIs, Slicers  
- Cleaned and transformed raw sales data  
- Built interactive dashboards using KPIs and charts  
- Analyzed sales trends and customer behavior  

### Power BI – Meta Ads Real-Time Performance Dashboard
*Tools:* Power BI, DAX (Basic)  
- Developed a real-time interactive dashboard  
- Tracked impressions, clicks, CTR, and conversions  
- Analyzed performance by audience and seasonality  

## Skills Demonstrated
- Data Cleaning & Analysis  
- Dashboard Development  
- Data Visualization  
- Business Insights
